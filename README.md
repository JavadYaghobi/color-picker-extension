# 🎨 Pixel Eyedropper — Chrome Color Picker Extension

A lightweight Chrome extension that lets you inspect and copy the exact color of any pixel on a webpage.

## ✨ Features

* **Double-click to activate** the eyedropper anywhere on the page.
* **Real-time magnifier** with pixel-perfect zoom for accurate color selection.
* Live **HEX** and **RGB** color preview.
* **One-click copy** of the selected HEX color to your clipboard.
* Press **Esc** to cancel at any time.
* Smooth, flicker-free performance with accurate color sampling.

## 🚀 How to Use

1. Enable the extension from the popup.
2. **Double-click anywhere** on a webpage to start the color picker.
3. Move your mouse to inspect colors.
4. Click to copy the HEX color.
5. Press **Esc** to exit.

## 🔒 Privacy

No data is collected or sent to any server. Everything runs locally in your browser.
